# Spotlight Reveal Photo · 聚光灯揭示照片 Skill

一个把单张照片变成「鼠标/手指聚光灯揭示」交互网页的 AI Skill。

平时页面上只显示**空场景**；当你移动鼠标（或在手机上滑动手指）时，会有一个柔和的光圈跟着你走。把光圈移到照片里的人（或物体）附近时，光圈会**自动放大**，把整个人从画面里「照」出来。纯前端、零依赖、单文件。

---

## 效果预览

```
  ┌──────────────── 浏览器全屏 ────────────────┐
  │                                              │
  │      [ 空场景：没有人的海滩 ]                 │
  │                  ◯ ← 小光圈跟着鼠标           │
  │                                              │
  │   鼠标移到人附近 → 光圈平滑放大 → 人显现      │
  └──────────────────────────────────────────────┘
```

- **桌面**：移动鼠标，光圈跟随；靠近人物，光圈放大。
- **手机**：手指滑动，光圈跟随；支持触屏。
- **竖图**：按原比例完整居中显示，两侧留白取天空/背景主色。

## 怎么用（推荐：交给 AI 生成）

把这个文件夹放到支持 Skill 的 AI 客户端（如豆包）的 skills 目录里，然后直接对 AI 说：

> 用我这张照片，做一个鼠标移过去显露出照片里的人的网页。

AI 会自动：
1. 先问你要哪张照片、要揭示的人/物在哪；
2. 用图片编辑把照片里的主体去掉、补成空场景；
3. 标定主体坐标；
4. 把两张图填进 `assets/template.html`，产出一个能直接打开的 `index.html`。

### 触发这个 Skill 的说法
- 「做一个鼠标移动显现照片里的人的网页」
- 「用这张照片做个聚光灯揭示效果」
- 「空背景，鼠标移过去照出人物」
- 「cursor spotlight reveal photo」

## 怎么自己手动改（不想用 AI 时）

打开 `assets/template.html`，替换这几个占位符：

| 占位符 | 含义 | 示例 |
| --- | --- | --- |
| `{{TITLE}}` | 网页标题 | `我的聚光灯照片` |
| `{{BG_COLOR}}` | 两侧/上下留白的底色 | `#63B3E8`（取天空色） |
| `{{BASE_IMG_URL}}` | 空场景图链接（底层） | `https://.../empty.jpg` |
| `{{REVEAL_IMG_URL}}` | 原图链接（顶层，带人物） | `https://.../original.jpg` |
| `{{IMG_W}}` `{{IMG_H}}` | 原图宽高（像素） | `1080` / `1440` |
| `{{PERSON_X}}` | 主体中心在原图里的 x（像素） | `820` |
| `{{PERSON_Y}}` | 主体中心在原图里的 y（像素） | `700` |
| `{{PERSON_EXTENT}}` | 照亮整个人需要的半径（像素） | `520` |

替换完另存为 `index.html`，双击用浏览器打开即可。

### 两张图怎么准备
- **原图**：你自己拍的/选的照片。
- **空场景图**：把主体去掉、背景自然补全。可以直接对 AI 说：
  > 把这张图里的人去掉，背景补成自然的空场景，构图、光线、色调和原图保持一致。

> 两张图必须是**同一场景、同一构图、只差主体本身**，否则光圈边缘会错位。

## 可调参数（在 template.html 底部 `<script>` 里）

- `HOVER_RANGE = 360`：指针离主体中心多近（屏幕像素）时光圈开始自动放大。
- `baseR`（约 120/160/260）：普通小光圈半径，按屏幕宽度自动分档。
- `extent * s`：放大后的半径，约等于人身高的 0.55~0.6 倍。
- 平滑系数 `0.2`：越大光圈变化越快（越灵敏），越小越柔。

## 常见问题

**Q：图片被裁切/只显示一部分？**
确认 CSS 用的是 `background-size: contain`（完整显示）。横屏想铺满才用 `cover`。

**Q：图片横向平铺成好几份？**
漏了 `background-repeat: no-repeat`，加上即可。

**Q：光圈放大后照偏了？**
`PERSON.x / PERSON.y` 没对准主体中心，或 `s` 与 CSS 的居中换算不一致。重新按主体中心调坐标。

**Q：手机上没反应？**
确认绑定了 `touchmove` 事件（模板已内置），并用手机浏览器打开。

---

## 原理一句话

两层图片叠放：底层空场景；顶层原图用 CSS `mask-image: radial-gradient(...)` 做圆形蒙版，JS 在 `mousemove / touchmove` 时实时更新这个圆的位置和半径——圆内透明（露出原图），圆外不透明（只看到空场景）。
